# Welcome to Fornax

<img src="https://raw.githubusercontent.com/nasa-fornax/fornax-documentation/refs/heads/main/_static/fornax_logo.png" alt="Fornax Science Console"
    style="float: right; width: 200px; margin: 10px;" />

Fornax is NASA's main Astrophysics Cloud platform that bring compute and software to the data, developed as a collaboration between NASA's three main Astrophysics data archives: [HEASARC](https://heasarc.gsfc.nasa.gov/),
[IRSA](https://irsa.ipac.caltech.edu/frontpage/), and [MAST](https://archive.stsci.edu/).

## Documentation & Support
Documentation for using the Fornax Science Console are available in [here](#fornax-command:fornax:web-tab-fornax-docs) (also available from the [documentation site](https://docs.fornax.sciencecloud.nasa.gov/)).
Help and support is available in the [Fornax discource forum](https://discourse.fornax.sciencecloud.nasa.gov).

## Tutorial Notebooks
Tutorials include both multi-archive Foranx full use cases and archive-specific tutorials. They are all listed below.
You can open and run notebooks available under `fornax-notebooks` in your home directory. Those come with all dependencies installed and ready to run.  You can also browse the rendered and pre-run versions as detailed below.


### Fornax Demo Notebooks:
Tutorial notebooks of fully worked science use cases.
The common goals of the notebooks are the usage of archival data from all NASA archives, cross-archive work, big data, and computationally intensive science.

- Run them inside: `~/fornax-notebooks/fornax-demo-notebooks`.
- Browser the [rendered pre-run version](#fornax-command:fornax:web-tab-fornax-nb).
- The [source](https://github.com/nasa-fornax/fornax-demo-notebooks) and [renderd](https://nasa-fornax.github.io/fornax-demo-notebooks/) repo on github.

### IRSA Tutorials:
Notebook tutorials that demonstrate access methods and techniques for working with data
served by the [NASA/IPAC Infrared Science Archive (IRSA)](https://irsa.ipac.caltech.edu/frontpage/).
They cover topics like querying IRSA,
working with catalogs in Parquet format, visualizing with Firefly, and general other techniques.

- Run them inside: `~/fornax-notebooks/irsa-tutorials`.
- Browser the [rendered pre-run version](#fornax-command:fornax:web-tab-irsa-nb).
- The [source](https://github.com/Caltech-IPAC/irsa-tutorials/) and [renderd](https://caltech-ipac.github.io/irsa-tutorials/) repo on github.

### HEASARC tutorials:
Notebook tutorials that demonstrate how find, access and analyze high energy
astrophysics data hosted at the [HEASARC](https://heasarc.gsfc.nasa.gov/).
They cover archive services as well as mission-specific data analyses.

- Run them inside: `~/fornax-notebooks/heasarc-tutorials`.
- Browser the [rendered pre-run version](#fornax-command:fornax:web-tab-heasarc-nb).
- The [source](https://github.com/heasarc/heasarc-tutorials) and [renderd](https://heasarc.github.io/heasarc-tutorials/) repo on github.

### MAST tutorials:
This is a collection of Jupyter Notebooks, written in Python,
that demonstrate methods of acccessing and analyzing data from the the
[Mikulski Archive for Space Telescopes](https://archive.stsci.edu/).

- Run them inside: `~/fornax-notebooks/mast-tutorials`.
- Browser the [rendered pre-run version](#fornax-command:fornax:web-tab-mast-nb).
- The [source](https://github.com/spacetelescope/mast_notebooks) and [renderd](https://spacetelescope.github.io/mast_notebooks/) repo on github.
